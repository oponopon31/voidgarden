Grow light in the dark. You are a wisp, the last seed of light in a garden overrun by blight. Shoot the blight motes, and every one you defeat blooms into a flower. Gather the flowers, survive the waves, and keep the garden glowing. An arena survival shooter in plain static files — no build step, no network requests. Move with WASD or arrows, aim with the mouse, shoot with hold-click or Space, dash with Shift or right-click. Three hearts, combo multipliers, and waves that grow denser and faster.

## Run it

```sh
node serve.ts
```

Then open the address it prints (port 8080 by default).
